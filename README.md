# Mini Avito

SPA на React, где можно просматривать список объявлений, смотреть детали каждого объявления и (по задумке) создавать/редактировать карточки через форму. Прототип сервиса объявлений (в духе Avito) со страницами интегрированными с REST API. Главные элементы интерфейса построены на MUI с кастомными компонентами. Приложение разработано в соответствии с методологией Feature-Sliced Design (FSD).
